# Структура проекта Tez Jumush для дизайнера

## 📱 Общее описание проекта

**Tez Jumush** - мобильное приложение для поиска и выполнения быстрых задач и подработок в Кыргызстане. Приложение соединяет работодателей с исполнителями.

## 🏗 Архитектура приложения

### Frontend (Мобильное приложение)
- **Технология:** React Native + Expo
- **Платформы:** iOS, Android, Web (PWA)
- **Язык:** JavaScript/React
- **Навигация:** React Navigation (табы + стек)

### Backend (API сервер)
- **Технология:** FastAPI (Python)
- **База данных:** PostgreSQL
- **Аутентификация:** JWT токены + Google Auth
- **SMS:** Twilio для верификации

## 📊 Модели данных

### User (Пользователь)
```javascript
{
  id: number,
  phone: string,           // +996XXXXXXXXX
  full_name: string,       // ФИО
  passport_series: string, // 7 цифр
  passport_number: string, // 14 цифр
  passport_issued_by: string, // до 11 символов
  passport_date: date,
  rating: number,          // 0-5
  created_at: datetime
}
```

### Task (Задача)
```javascript
{
  id: number,
  title: string,           // Название задачи
  description: string,     // Описание
  price: number,           // Цена в сомах
  count_people: number,    // Количество людей
  date: date,              // Дата выполнения
  time: time,              // Время выполнения
  address: string,         // Адрес
  latitude: number,        // Координаты
  longitude: number,
  user_id: number,         // ID создателя
  status: string,          // active/completed/cancelled
  created_at: datetime
}
```

### Message (Сообщение)
```javascript
{
  id: number,
  sender_id: number,       // Отправитель
  receiver_id: number,     // Получатель
  task_id: number,         // Связанная задача
  text: string,            // Текст сообщения
  is_read: boolean,        // Прочитано
  timestamp: datetime
}
```

## 🎯 Основные функции приложения

### 1. Регистрация и вход
- SMS верификация номера телефона (+996)
- Ввод паспортных данных
- Вход через Google (опционально)
- Автоматическое сохранение сессии

### 2. Просмотр задач
- Список всех активных задач
- Фильтрация по цене, дате, расстоянию
- Поиск по названию
- Сортировка по различным критериям

### 3. Карта задач
- Интерактивная карта с маркерами
- Геолокация пользователя
- Поиск задач поблизости
- Кластеризация маркеров

### 4. Создание задач
- Форма с полями: название, описание, цена
- Выбор даты и времени
- Указание количества людей
- Выбор адреса на карте
- Автоматическое определение координат

### 5. Управление задачами
- Просмотр своих созданных задач
- Редактирование активных задач
- Отмена задач
- Просмотр заявок от исполнителей

### 6. Система чатов
- Список всех переписок
- Real-time сообщения
- Привязка чатов к задачам
- Статус прочтения сообщений

### 7. Профиль пользователя
- Просмотр и редактирование данных
- История выполненных задач
- Рейтинг пользователя
- Настройки приложения

## 🎨 Дизайн-система

### Цветовая схема
- **Основной цвет:** #007AFF (синий)
- **Фон:** #f5f5f5 (светло-серый)
- **Текст:** #333333 (темно-серый)
- **Ошибки:** #f44336 (красный)
- **Успех:** #4CAF50 (зеленый)

### Типографика
- **Заголовки:** 18-24px, жирный
- **Основной текст:** 16px, обычный
- **Подписи:** 14px, светлый

## 📋 Пользовательские сценарии

### Сценарий 1: Поиск задачи
1. Пользователь открывает приложение
2. Просматривает список задач
3. Использует фильтры (цена, дата, расстояние)
4. Открывает детали интересной задачи
5. Связывается с работодателем через чат

### Сценарий 2: Создание задачи
1. Пользователь нажимает "Добавить задачу"
2. Заполняет форму (название, описание, цена)
3. Выбирает дату и время
4. Указывает адрес на карте
5. Публикует задачу

### Сценарий 3: Управление задачами
1. Пользователь переходит в "Мои задачи"
2. Видит список своих задач
3. Может редактировать активные задачи
4. Просматривает заявки от исполнителей
5. Выбирает исполнителя и начинает чат
