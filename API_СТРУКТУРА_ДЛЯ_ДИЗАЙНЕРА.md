# API структура для дизайнера - Tez Jumush

## 🔗 Основные API endpoints

### Базовый URL
- **Локальная разработка:** http://localhost:8000
- **API документация:** http://localhost:8000/docs

## 🔐 Аутентификация

### SMS верификация
```
POST /sms/send-code
POST /sms/verify-code
GET /sms/status/{phone}
```

### Авторизация
```
POST /auth/register    - Регистрация пользователя
POST /auth/login       - Вход в систему
GET /auth/me          - Получение текущего пользователя
```

### Google Auth
```
POST /auth/google      - Вход через Google
GET /auth/google/user  - Получение данных Google пользователя
```

## 📋 Задачи (Tasks)

### Основные операции
```
GET /tasks/           - Список всех задач
GET /tasks/nearby     - Задачи поблизости
GET /tasks/{id}       - Детали конкретной задачи
POST /tasks/          - Создание новой задачи
PUT /tasks/{id}       - Редактирование задачи
DELETE /tasks/{id}    - Удаление задачи
```

### Параметры фильтрации
- `min_price` - минимальная цена
- `max_price` - максимальная цена
- `date_from` - дата от
- `date_to` - дата до
- `latitude` - широта для поиска поблизости
- `longitude` - долгота для поиска поблизости
- `radius` - радиус поиска в км

## 👥 Пользователи (Users)

### Операции с пользователями
```
GET /users/phone/{phone}  - Поиск по номеру телефона
GET /users/{id}          - Профиль пользователя
PUT /users/{id}          - Обновление профиля
```

## 💬 Чаты (Chats)

### Сообщения
```
GET /chats/                    - Список всех чатов
GET /chats/{id}/messages       - Сообщения конкретного чата
POST /chats/{id}/messages      - Отправка сообщения
PUT /chats/messages/{id}/read  - Отметить как прочитанное
```

## 🆘 Поддержка (Support)

### Обратная связь
```
POST /support/feedback  - Отправка отзыва/жалобы
GET /support/faq       - Часто задаваемые вопросы
```

## 🎨 Состояния UI элементов

### Статусы задач
- **active** - Активная (зеленый цвет)
- **completed** - Завершенная (серый цвет)
- **cancelled** - Отмененная (красный цвет)

### Статусы пользователей
- **online** - В сети (зеленая точка)
- **offline** - Не в сети (серая точка)
- **verified** - Верифицированный (синяя галочка)

### Статусы сообщений
- **sent** - Отправлено (одна галочка)
- **delivered** - Доставлено (две галочки)
- **read** - Прочитано (две синие галочки)

## 📱 Экраны и их данные

### TasksScreen - Список задач
**Данные:** Массив задач с пагинацией
**Фильтры:** Цена, дата, расстояние, категория
**Сортировка:** По дате, цене, расстоянию

### MapScreen - Карта задач
**Данные:** Задачи с координатами
**Функции:** Кластеризация маркеров, текущее местоположение

### TaskDetailScreen - Детали задачи
**Данные:** Полная информация о задаче + профиль создателя
**Действия:** Откликнуться, написать сообщение, поделиться

### AddTaskScreen - Создание задачи
**Поля:** Название, описание, цена, количество людей, дата, время, адрес
**Валидация:** Обязательные поля, формат данных

### MyTasksScreen - Мои задачи
**Данные:** Задачи пользователя (созданные и взятые)
**Фильтры:** По статусу, по дате
**Действия:** Редактировать, отменить, завершить

### ChatsScreen - Чаты
**Данные:** Список чатов с последними сообщениями
**Функции:** Поиск по чатам, статус прочтения

### ProfileScreen - Профиль
**Данные:** Информация о пользователе, статистика, настройки
**Действия:** Редактировать профиль, выйти из аккаунта

## 🔄 Состояния загрузки

### Загрузка данных
- **Loading** - Показать скелетон или спиннер
- **Error** - Показать сообщение об ошибке с кнопкой повтора
- **Empty** - Показать сообщение "Нет данных"
- **Success** - Показать данные

### Отправка данных
- **Idle** - Обычное состояние кнопки
- **Loading** - Кнопка заблокирована, показать спиннер
- **Success** - Показать успешное сообщение
- **Error** - Показать ошибку

## 🌐 Поддержка офлайн режима

### Кэшированные данные
- Список задач (последние 50)
- Профиль пользователя
- История чатов
- Настройки приложения

### Синхронизация
- Автоматическая синхронизация при подключении к интернету
- Индикатор статуса синхронизации
- Конфликты данных - приоритет серверным данным

## 📐 Размеры и отступы

### Стандартные отступы
- **Маленький:** 8px
- **Средний:** 16px
- **Большой:** 24px

### Размеры элементов
- **Высота кнопки:** 48px
- **Высота поля ввода:** 48px

- **Кнопки:** 8px
- **Карточки:** 12px
- **Модальные окна:** 16px
- **Аватары:** 50% (круглые)
