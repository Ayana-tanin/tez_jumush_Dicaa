# Примеры экранов для дизайнера - Tez Jumush

## 📱 Детальное описание экранов

### 1. Экран авторизации (AuthScreen)

**Элементы интерфейса:**
- Логотип приложения "Tez Jumush"
- Поле ввода номера телефона (+996)
- Кнопка "Получить код"
- Поле ввода SMS кода (4 цифры)
- Кнопка "Войти"
- Ссылка "Повторить отправку кода"
- Индикатор времени (обратный отсчет)

**Состояния:**
- Ввод номера телефона
- Ожидание SMS кода
- Ввод SMS кода
- Загрузка/проверка кода
- Ошибка (неверный код, истек срок)

### 2. Главный экран - Список задач (TasksScreen)

**Верхняя панель:**
- Заголовок "Задачи"
- Поле поиска с иконкой лупы
- Кнопка фильтров

**Фильтры (горизонтальная прокрутка):**
- "Все" (активный)
- "Сегодня"
- "На неделе"
- "В этом месяце"

- Карта

### 3. Экран карты (MapScreen)

**Элементы:**
- Полноэкранная карта
- Маркеры задач (кластеризация)
- Кнопка "Мое местоположение"
- Поиск по адресу (сверху)
- Карточка выбранной задачи (снизу)

**Маркеры:**
- Обычная задача: синий маркер с ценой
- Срочная задача: красный маркер
- Моя задача: зеленый маркер

### 5. Создание задачи (AddTaskScreen)

**Форма создания:**
- Название задачи (обязательно)
- Описание задачи (обязательно)
- Цена в сомах (обязательно)
- Количество людей (по умолчанию 1)
- Дата выполнения (календарь)
- Время выполнения (время)
- Адрес (с выбором на карте)
- Кнопка "Опубликовать задачу"

**Валидация:**
- Красная рамка для незаполненных полей
- Подсказки под полями
- Блокировка кнопки до заполнения

## 🎨 Компоненты интерфейса

### Кнопки
**Основная кнопка:**
- Высота: 48px
- Скругление: 8px
- Цвет: #007AFF
- Текст: белый, 16px, жирный

**Вторичная кнопка:**
- Высота: 48px
- Скругление: 8px
- Цвет: прозрачный
- Рамка: #007AFF
- Текст: #007AFF, 16px

### Поля ввода
- Высота: 48px
- Скругление: 8px
- Рамка: #E0E0E0
- Фокус: #007AFF
- Ошибка: #F44336
- Placeholder: #999999

### Карточки
- Фон: белый
- Скругление: 12px
- Тень: 0 2px 8px rgba(0,0,0,0.1)
- Отступы: 16px

### Иконки
- Размер: 24px (обычные), 20px (в табах)
- Цвет: #666666 (неактивные), #007AFF (активные)

## 📊 Состояния экранов

### Загрузка
- Скелетон для списков
- Спиннер для кнопок
- Shimmer эффект для карточек

### Пустое состояние
- Иконка
- Заголовок
- Описание
- Кнопка действия (если нужна)

### Ошибка
- Иконка ошибки
- Сообщение об ошибке
- Кнопка "Повторить"

## 🔄 Анимации и переходы

### Переходы между экранами
- Slide (горизонтальный) для стека
- Fade для модальных окон
- Scale для всплывающих окон

### Микроанимации
- Нажатие кнопок (scale 0.95)
- Появление элементов (fade + slide)
- Загрузка (rotation для спиннеров)

### Жесты
- Swipe для удаления элементов
- Pull-to-refresh для списков
- Pinch-to-zoom для карты

## 📱 Адаптация под платформы

### iOS
- Использование системных шрифтов
- Соблюдение Human Interface Guidelines
- Safe Area для iPhone X+

### Android
- Material Design элементы
- Системная навигация
- Адаптация под разные размеры экранов

### Web (PWA)
- Адаптивная верстка
- Поддержка клавиатуры
- Hover эффекты для десктопа
