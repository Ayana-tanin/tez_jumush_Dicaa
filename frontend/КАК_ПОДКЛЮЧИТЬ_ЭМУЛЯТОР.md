# 📱 Как подключить Android эмулятор в ноутбуке для Expo Go

## 🎯 Цель
Запустить Android эмулятор на ноутбуке, установить в него Expo Go и подключиться к вашему приложению через QR-код.

---

## 📋 Шаг 1: Установка Android Studio

### 1.1 Скачайте Android Studio
- Перейдите на: https://developer.android.com/studio
- Скачайте установщик для Windows
- Запустите установщик

### 1.2 Установка
1. Выберите "Standard" установку
2. Дождитесь загрузки компонентов (может занять 10-30 минут)
3. После установки запустите Android Studio

### 1.3 Первый запуск
1. Android Studio предложит установить Android SDK - согласитесь
2. Дождитесь завершения установки SDK
3. Примите лицензионные соглашения

---

## 📱 Шаг 2: Создание виртуального устройства (AVD)

### 2.1 Откройте AVD Manager
1. В Android Studio нажмите на иконку **"Device Manager"** (справа вверху)
   - Или: **Tools → Device Manager**

### 2.2 Создайте новое устройство
1. Нажмите **"Create Device"**
2. Выберите устройство:
   - Рекомендуется: **Pixel 5** или **Pixel 6**
   - Или любой другой телефон
3. Нажмите **"Next"**

### 2.3 Выберите системный образ
1. Выберите версию Android:
   - Рекомендуется: **Android 13 (Tiramisu)** или **Android 12 (S)**
   - Если нет - нажмите **"Download"** рядом с нужной версией
2. Дождитесь загрузки (может занять 5-15 минут)
3. Нажмите **"Next"**

### 2.4 Настройте устройство
1. Оставьте настройки по умолчанию или измените:
   - **Name**: Pixel 5 API 33 (или любое имя)
   - **RAM**: минимум 2GB (рекомендуется 4GB)
   - **Graphics**: Automatic
2. Нажмите **"Finish"**

---

## 🚀 Шаг 3: Запуск эмулятора

### 3.1 Запустите эмулятор
1. В **Device Manager** найдите созданное устройство
2. Нажмите кнопку **▶️ Play** (треугольник) рядом с устройством
3. Дождитесь полной загрузки эмулятора (2-5 минут при первом запуске)

### 3.2 Проверка работы
- Эмулятор должен показать экран Android
- Должен работать как обычный телефон
- Можно использовать мышь и клавиатуру

---

## 📲 Шаг 4: Установка Expo Go в эмуляторе

### 4.1 Откройте Google Play в эмуляторе
1. В эмуляторе найдите иконку **Google Play Store**
2. Если нет - нужно установить образ с Google Play (GMS)

### 4.2 Установите Expo Go
1. В Play Store найдите **"Expo Go"**
2. Или перейдите по ссылке: https://play.google.com/store/apps/details?id=host.exp.exponent
3. Нажмите **"Install"**
4. Дождитесь установки

### 4.3 Альтернатива: Установка APK напрямую
Если Play Store не работает:

1. Скачайте APK Expo Go:
   - Перейдите: https://expo.dev/tools
   - Или: https://github.com/expo/expo/releases
   - Скачайте последнюю версию `expo-go.apk`

2. Установите APK:
   ```powershell
   # Перетащите APK файл в эмулятор
   # Или используйте команду:
   adb install путь\к\файлу\expo-go.apk
   ```

---

## 🔗 Шаг 5: Подключение к приложению

### 5.1 Запустите сервер разработки
В PowerShell выполните:

```powershell
cd frontend
npm run start:lan
```

Или если не работает:

```powershell
cd frontend
npm start
```

### 5.2 Получите IP адрес компьютера
В PowerShell выполните:

```powershell
ipconfig
```

Найдите **IPv4 Address** (например: `192.168.1.100`)

### 5.3 Откройте Expo Go в эмуляторе
1. Запустите **Expo Go** в эмуляторе
2. Нажмите **"Scan QR code"** или **"Enter URL manually"**

### 5.4 Подключитесь к серверу

**Вариант A: Через QR-код**
1. В терминале должен появиться QR-код
2. В эмуляторе откройте камеру (или используйте функцию сканирования в Expo Go)
3. Отсканируйте QR-код

**Вариант B: Через URL вручную**
1. В Expo Go выберите **"Enter URL manually"**
2. Введите URL из терминала (например: `exp://192.168.1.100:8081`)
3. Или используйте формат: `exp://ВАШ_IP:8081`

---

## ⚙️ Шаг 6: Настройка сети (если не работает)

### 6.1 Проверьте, что эмулятор видит компьютер
В эмуляторе откройте браузер и перейдите:
```
http://ВАШ_IP:8081
```

Должна открыться страница Expo.

### 6.2 Настройте порты
Если порты заблокированы:

1. Откройте **Windows Firewall**
2. Добавьте исключение для портов:
   - `8081` (Metro bundler)
   - `19000` (Expo)
   - `19001` (Expo)
   - `19002` (Expo)

### 6.3 Используйте localhost (альтернатива)
Если LAN не работает, попробуйте:

```powershell
cd frontend
npx expo start --localhost
```

Затем в эмуляторе используйте:
```
exp://10.0.2.2:8081
```

**Примечание:** `10.0.2.2` - это специальный IP адрес, который эмулятор использует для доступа к localhost компьютера.

## 🔧 Решение проблем

### Проблема 1: Эмулятор не запускается
**Решение:**
- Убедитесь, что включена виртуализация в BIOS
- Проверьте, что HAXM или Hyper-V включен
- Попробуйте уменьшить RAM эмулятора

### Проблема 2: Expo Go не может подключиться
**Решение:**
- Проверьте, что компьютер и эмулятор в одной сети
- Используйте `--localhost` и IP `10.0.2.2`
- Проверьте firewall

### Проблема 3: QR-код не сканируется
**Решение:**
- Используйте "Enter URL manually" в Expo Go
- Введите URL вручную: `exp://10.0.2.2:8081`

### Проблема 4: Эмулятор медленный
**Решение:**
- Увеличьте RAM эмулятора (4GB+)
- Используйте x86/x86_64 образ вместо ARM
- Включите аппаратное ускорение

## 📊 Проверка подключения

### Проверка 1: Эмулятор запущен?
```powershell
adb devices
```
Должно показать:
```
List of devices attached
emulator-5554    device
```

### Проверка 2: Сервер запущен?
Откройте в браузере: `http://localhost:8081`
Должна открыться страница Metro bundler.

### Проверка 3: Expo Go установлен?
В эмуляторе найдите иконку Expo Go.

## ✅ Итоговая последовательность действий

2. ✅ Создайте виртуальное устройство (AVD)
3. ✅ Запустите эмулятор
4. ✅ Установите Expo Go в эмуляторе
5. ✅ Запустите сервер: `npm run start:lan`
6. ✅ Откройте Expo Go в эмуляторе
7. ✅ Отсканируйте QR-код или введите URL вручную
8. ✅ Приложение загрузится в эмуляторе! 🎉

---

## 💡 Полезные советы

- **Производительность**: Используйте x86 образы для лучшей производительности
- **Размер экрана**: Выберите размер эмулятора, удобный для вашего ноутбука
- **Снимки экрана**: Используйте кнопку камеры в панели эмулятора
- **Поворот экрана**: Ctrl+F11 или Ctrl+F12 для поворота

## 🚀 Альтернатива: Использовать веб-версию

```powershell
cd frontend
npm run web
```

Приложение откроется в браузере. Можно включить режим мобильного устройства (F12 → Ctrl+Shift+M).
