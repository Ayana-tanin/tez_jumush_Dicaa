# Обзор функционала регистрации и авторизации

## ✅ Реализованный функционал

### 1. Экран выбора роли (AuthScreen.js)
- **Функционал:**
  - Отображение экрана выбора роли (Работодатель/Работник)
  - Навигация к соответствующей странице регистрации в зависимости от выбора
  - Обработка сохранения данных анкеты
  - Создание гостевого аккаунта, если пользователь не авторизован
  - Индикатор загрузки при сохранении данных

- **Особенности:**
  - Автоматический переход к основному приложению после успешной регистрации
  - Сохранение данных в профиль пользователя через GoogleAuthService
  - Обработка ошибок с показом Alert

### 2. Регистрация работника (RegWorker.js)
- **Функционал:**
  - Форма регистрации с полями:
    - Возраст (валидация: 18-100 лет)
    - Опыт работы
    - Район проживания
    - Номер телефона (валидация формата)
  - Кнопка "Назад" для возврата к выбору роли
  - Индикатор загрузки при сохранении
  - Валидация всех полей перед отправкой

- **Валидация:**
  - Проверка заполненности всех полей
  - Проверка корректности возраста
  - Проверка формата номера телефона

### 3. Регистрация работодателя (RegestrationEmpl.js)
- **Функционал:**
  - Аналогичная форма регистрации как для работника
  - Те же поля и валидация
  - Кнопка "Назад" для возврата к выбору роли
  - Индикатор загрузки при сохранении

### 4. Профиль пользователя (UserProfileScreen.js)
- **Функционал:**
  - Отображение базовой информации пользователя
  - **Секция "Анкета"** с отображением:
    - Роль (Работодатель/Работник)
    - Возраст
    - Опыт работы
    - Район проживания
    - Телефон
  - Редактирование имени
  - Статистика пользователя
  - Настройки
  - Выход из аккаунта

- **Особенности:**
  - Секция анкеты отображается только если `registrationCompleted === true`
  - Красивое оформление с иконками для каждого поля
  - Адаптивный дизайн

### 5. Система авторизации (App.js)
- **Функционал:**
  - Проверка статуса авторизации при запуске приложения
  - Поддержка:
    - Google Auth
    - Гостевой аккаунт
    - PWA (localStorage)
    - Legacy токены (AsyncStorage)
  - Проверка завершенности регистрации (`registrationCompleted`)
  - Автоматический переход к основному приложению или экрану регистрации

- **Логика проверки:**
  1. Проверка PWA токенов (для веб-версии)
  2. Проверка Google Auth статуса
  3. Проверка legacy токенов
  4. Во всех случаях проверяется наличие `registrationCompleted`

### 6. Сервис авторизации (googleAuth.js)
- **Функционал:**
  - Сохранение данных пользователя (включая гостевой аккаунт)
  - Обновление профиля пользователя
  - Проверка статуса авторизации
  - Выход из аккаунта
  - Поддержка гостевого режима

- **Особенности:**
  - Правильная обработка гостевых аккаунтов
  - Сохранение метода входа (google/guest)
  - Обработка ошибок

## 🔄 Поток работы приложения

### Первый запуск:
1. Пользователь видит экран выбора роли (AuthScreen)
2. Выбирает роль (Работодатель/Работник)
3. Переходит на страницу регистрации (RegWorker/RegestrationEmpl)
4. Заполняет форму
5. Нажимает "Продолжить"
6. Данные сохраняются в профиль
7. Создается гостевой аккаунт (если не авторизован через Google)
8. Автоматический переход к основному приложению

### Повторный запуск:
1. Проверка статуса авторизации
2. Если `registrationCompleted === true` → показ основного приложения
3. Если нет → показ экрана выбора роли

### Выход из аккаунта:
1. Очистка всех данных (токен, userData, loginMethod)
2. Возврат к экрану выбора роли

## 📋 Сохраняемые данные

### В профиле пользователя сохраняется:
```javascript
{
  id: string,
  name: string,
  email: string,
  role: 'employer' | 'worker',
  age: string,
  experience: string,
  district: string,
  phone: string,
  registrationCompleted: true,
  isGuest: boolean (опционально),
  loginMethod: 'google' | 'guest',
  loginTime: ISO string,
  updatedAt: ISO string
}
```
