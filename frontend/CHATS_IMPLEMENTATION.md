r# 💬 Реализация системы чатов

## ✅ Что реализовано:

### 1. **Экран списка чатов (ChatsScreen.js)**
- Список всех переписок
- Рабочие фильтры: Все, Сегодня, На неделе, В этом месяце
- Навигация к конкретному чату при нажатии
- Красивые карточки чатов с аватарами

### 2. **Экран переписки (ChatScreen.js)**
- Отображение сообщений (свои справа, чужие слева)
- Отправка сообщений
- Автоматическое сохранение в AsyncStorage
- Автопрокрутка к новым сообщениям
- Поддержка клавиатуры (KeyboardAvoidingView)
- Автоматические ответы для демонстрации

### 3. **Навигация**
- Добавлен экран `Chat` в `MainNavigator.js`
- Передача параметров: `chatId`, `chatTitle`, `otherUserName`
- Header с кнопкой "Назад"

## 📁 Структура файлов:

```
src/screens/Chats/
├── ChatsScreen.js    # Список чатов с фильтрами
└── ChatScreen.js     # Экран переписки
```

## 🔄 Как это работает:

### Открытие чата:
1. Пользователь нажимает на чат в списке
2. Переход на экран `Chat` с параметрами:
   ```javascript
   navigation.navigate('Chat', {
     chatId: '1',
     chatTitle: 'Посадка картофеля',
     otherUserName: 'Алексей М.'
   });
   ```

### Хранение сообщений:
- Сообщения сохраняются в `AsyncStorage` с ключом `@chat_messages_{chatId}`
- Каждый чат имеет свой набор сообщений
- Сообщения сохраняются автоматически при отправке

### Фильтры:
- **Все** - показывает все чаты
- **Сегодня** - чаты с сообщениями сегодня
- **На неделе** - чаты на этой неделе
- **В этом месяце** - чаты в текущем месяце

## 🎨 Дизайн:

### ChatsScreen:
- Фильтры вверху (горизонтальный скролл)
- Карточки чатов с:
  - Аватаром (инициалы пользователя)
  - Названием задачи
  - Последним сообщением
  - Временем
  - Стрелкой для навигации

### ChatScreen:
- Сообщения слева (чужие) и справа (свои)
- Свои сообщения: синий фон (#2F80ED)
- Чужие сообщения: белый фон с тенью
- Поле ввода внизу с кнопкой отправки
- Автопрокрутка к новым сообщениям

## 📝 Пример использования:


## 🔧 Настройка:

### Добавление новых чатов:
Измените массив `MOCK_CHATS` в `ChatsScreen.js`:

```javascript
const MOCK_CHATS = [
  { 
    id: '1', 
    title: 'Название задачи', 
    subtitle: 'Последнее сообщение', 
    time: '11:30', 
    userName: 'Имя пользователя' 
  },
  // ...
];
```

### Изменение стилей:
Все стили находятся в `StyleSheet.create()` в конце каждого файла.

## ✅ Готово к использованию!

Система чатов полностью рабочая и готова к использованию. Все сообщения сохраняются локально и будут доступны после перезапуска приложения.
