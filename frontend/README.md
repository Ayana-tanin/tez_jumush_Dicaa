# Tez Jumush - Мобильное приложение

Мобильное приложение для быстрого поиска работы и работников в Кыргызстане.

## Функциональность

### 🔐 Аутентификация
- Регистрация с номером телефона, ФИО и паспортными данными
- Загрузка фотографий паспорта (лицевая и обратная сторона)
- Вход в существующий аккаунт

### 📱 Основные экраны

#### 1. Задачи (Tasks)
- Новостной портал "Кто мы такие"
- Поиск и фильтрация задач
- Список актуальных работ с детальной информацией
- Рейтинг работодателей
- Полное описание работы при нажатии

#### 2. Карта (Map)
- Отображение текущего местоположения
- Иконки задач на карте с разными цветами по типам
- Легенда типов работ
- Кнопка обновления местоположения

#### 3. Добавить задачу (Add Task)
- Форма создания новой задачи
- Выбор категории работы
- Указание стоимости, длительности, даты и времени
- Выбор количества необходимых людей
- Автоматическое определение адреса по геолокации

#### 4. Переписки (Chats)
- Активные и архивные переписки
- Поиск по имени или названию задачи
- Счетчики непрочитанных сообщений
- Информация о работодателе/работнике

#### 5. Профиль (Profile)
- Данные пользователя с возможностью редактирования
- Статистика (рейтинг, количество выполненных задач)
- Настройки уведомлений и геолокации
- Управление картами
- Завершение регистрации/идентификация
- Служба поддержки
- Выход из аккаунта

## Технологии

- **React Native** с Expo
- **React Navigation** для навигации
- **React Native Maps** для карт
- **Expo Location** для геолокации
- **Expo Image Picker** для работы с камерой
- **AsyncStorage** для локального хранения

## Установка и запуск

### Предварительные требования
- Node.js (версия 16 или выше)
- npm или yarn
- Expo CLI: `npm install -g @expo/cli`
- Expo Go приложение на телефоне (для тестирования)

### Установка зависимостей
```bash
cd frontend
npm install
```

### Запуск приложения
```bash
# Запуск в режиме разработки
npm start

# Запуск на Android
npm run android

# Запуск на iOS (только на macOS)
npm run ios

# Запуск в веб-браузере
npm run web
```

### Тестирование на устройстве
1. Установите Expo Go из App Store или Google Play
2. Запустите `npm start`
3. Отсканируйте QR-код в приложении Expo Go

📱 **Подробное руководство по тестированию на iPhone (Expo Go и TestFlight)**: см. [КАК_ТЕСТИРОВАТЬ_НА_IPHONE.md](./КАК_ТЕСТИРОВАТЬ_НА_IPHONE.md)

## Особенности

- **Адаптивный дизайн** для разных размеров экранов
- **Темная/светлая тема** (настраивается в системе)
- **Геолокация** для показа ближайших задач
- **Офлайн режим** для просмотра сохраненных данных
- **Push-уведомления** (планируется)
- **Многоязычность** (планируется)
