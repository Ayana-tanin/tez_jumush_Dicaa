# Единая шапка и нижняя панель навигации

## 📋 Описание

Реализована единая система навигации с:
- **Единым Header** для всех экранов
- **Единой нижней панелью** (разной для работодателей и работников)

## 🎨 Компоненты

### 1. Header (`src/components/Header.js`)
Единый компонент шапки для всех экранов:
- Логотип "TEZ JUMUSH" (или кнопка "Назад" при необходимости)
- Заголовок экрана (опционально)
- Иконка уведомлений (или кастомный компонент справа)

**Использование:**
```jsx
<Header 
  role="employer" // или "worker"
  title="Задачи"  // опционально
  showBack={false} // показывать кнопку "Назад"
  onNotificationPress={() => {}} // обработчик уведомлений
/>
```

### 2. ScreenWrapper (`src/components/ScreenWrapper.js`)
Обертка для экранов, которая автоматически добавляет Header:
- Автоматически определяет роль пользователя
- Добавляет Header с правильными настройками
- Упрощает использование на всех экранах

**Использование:**
```jsx
<ScreenWrapper 
  title="Задачи"
  showBack={false}
  showHeader={true}
>
  <YourScreen />
</ScreenWrapper>
```

### 3. Кастомный TabBar (в `MainNavigator.js`)
Единая нижняя панель навигации:
- **Для работников:** Задачи | Мои отклики | Чаты | Профиль
- **Для работодателей:** Задачи | Отклики| Создать | Чаты | Профиль

## 🔄 Различия по ролям

### Работник (Worker)
**Нижняя панель:**
1. Задачи - список всех доступных задач
2. Мои отклики - задачи, на которые работник откликнулся 
3. Чаты - переписки с работодателями
4. Профиль - личный профиль

### Работодатель (Employer)
**Нижняя панель:**
1. Задачи - список всех задач
2. Отклики - отклики на созданные задачи
3. Создать - создание новой задачи
4. Чаты - переписки с работниками 
5. Профиль - личный профиль

## 📱 Интеграция

Все экраны в `MainNavigator.js` обернуты в `ScreenWrapper`:

```jsx
<Tab.Screen name="Tasks">
  {(props) => (
    <ScreenWrapper title="Задачи">
      <OfflineTasksScreen {...props} />
    </ScreenWrapper>
  )}
</Tab.Screen>
```

## 🎯 Особенности

1. **Автоматическое определение роли** - роль определяется из GoogleAuthService
2. **Единый стиль** - все экраны имеют одинаковый Header
3. **Гибкость** - можно скрыть Header или добавить кастомные элементы
4. **Адаптивность** - учитывает платформу (iOS/Android/Web)

## 🔧 Настройка

### Изменить стиль Header:
Отредактируйте `src/components/Header.js`

### Изменить нижнюю панель:
Отредактируйте `CustomTabBar` в `src/navigation/MainNavigator.js`

### Добавить новый экран:
1. Оберните экран в `ScreenWrapper`
2. Добавьте в `Tab.Navigator` или `Stack.Navigator`
3. Укажите правильный `title` в `ScreenWrapper`

## 📝 Примеры

### Экран с Header и Back кнопкой:
```jsx
<ScreenWrapper 
  title="Детали задачи" 
  showBack={true}
  showBottomNav={false} // скрыть нижнюю панель на детальных экранах
>
  <TaskDetailScreen />
</ScreenWrapper>
```

### Экран с кастомным правым компонентом:
```jsx
<ScreenWrapper 
  title="Задачи"
  rightComponent={<CustomButton />}
>
  <TasksScreen />
</ScreenWrapper>
```
