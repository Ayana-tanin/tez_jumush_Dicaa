### 1. Переменные окружения

Убедитесь, что установлены переменные окружения (если используются):

```bash
# .env файл в папке frontend
EXPO_PUBLIC_API_BASE_URL=http://your-api-url:8000
EXPO_PUBLIC_GOOGLE_ANDROID_CLIENT_ID=your-android-client-id
EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID=your-ios-client-id
EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=your-web-client-id
```

### 2. API URL для мобильных устройств

В файлах используется IP адрес для разработки:
- `src/utils/api.js` - IP: `10.62.74.121`
- `src/screens/LoginAndRegistration/CodeVerificationScreen.js` - IP: `10.62.74.121`

**⚠️ Важно:** Перед тестированием на реальных устройствах:
1. Убедитесь, что ваш компьютер и телефон в одной сети Wi-Fi
2. Узнайте ваш IP адрес: `ipconfig` (Windows) или `ifconfig` (Mac/Linux)
3. Обновите IP в файлах или используйте переменную окружения `EXPO_PUBLIC_API_BASE_URL`

## 🐛 Потенциальные проблемы и решения

### Проблема 1: Не работает подключение к API

**Причина:** Неправильный IP адрес или устройство не в той же сети

**Решение:**
1. Проверьте IP адрес компьютера
2. Обновите IP в `src/utils/api.js` или используйте `EXPO_PUBLIC_API_BASE_URL`
3. Убедитесь, что телефон и компьютер в одной Wi-Fi сети
4. Используйте `--tunnel` режим для Expo Go

### Проблема 2: Google OAuth не работает

**Причина:** Не настроены Client IDs

**Решение:**
1. Создайте OAuth credentials в Google Cloud Console
2. Добавьте переменные окружения:
   - `EXPO_PUBLIC_GOOGLE_ANDROID_CLIENT_ID`
   - `EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID`
3. Убедитесь, что они не содержат `YOUR_` или placeholder значения

### Проблема 3: Геолокация не работает

**Причина:** Не даны разрешения

**Решение:**
1. Проверьте настройки разрешений в `app.json`
2. На реальном устройстве предоставьте разрешения в настройках
3. iOS требует описание в `infoPlist` (уже настроено)

### Проблема 4: Камера не работает

**Причина:** Не даны разрешения

**Решение:**
1. Проверьте настройки разрешений в `app.json`
2. Android требует разрешения в `android.permissions` (уже настроено)
3. На реальном устройстве предоставьте разрешения
