# 📱 Как запустить мобильную версию приложения

## Вариант 1: Expo Go на телефоне (РЕКОМЕНДУЕТСЯ) ✅

### Шаг 1: Установите Expo Go
- **Android**: [Google Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent)
- **iOS**: [App Store](https://apps.apple.com/app/expo-go/id982107779)

### Шаг 2: Запустите сервер с QR-кодом

**В PowerShell выполните:**
```bash
cd frontend
npm run start:tunnel
```

Или если tunnel не работает, попробуйте:
```bash
cd frontend
npm start
```
Затем в меню Expo нажмите `s` для выбора режима и выберите `tunnel` или `lan`.

### Шаг 3: Отсканируйте QR-код
1. Откройте приложение **Expo Go** на телефоне
2. Нажмите "Scan QR code"
3. Отсканируйте QR-код из терминала
4. Приложение загрузится на ваш телефон!

---

## Вариант 2: Веб-версия (работает как мобильная) 🌐

**В PowerShell выполните:**
```bash
cd frontend
npm run web
```

Приложение откроется в браузере. Вы можете:
- Открыть DevTools (F12)
- Включить режим мобильного устройства (Ctrl+Shift+M)
- Выбрать размер экрана телефона

---

## Вариант 3: Подключить Android телефон через USB 📲

### Требования:
1. Android телефон с включенной отладкой по USB
2. USB кабель
3. Драйверы ADB

### Шаги:
1. На телефоне: **Настройки → О телефоне → Нажмите 7 раз на "Номер сборки"**
2. Включите: **Настройки → Для разработчиков → Отладка по USB**
3. Подключите телефон к компьютеру через USB
4. Запустите:
   ```bash
   cd frontend
   npm start
   ```
5. Нажмите `a` в меню Expo для открытия на Android

---

## Вариант 4: Android эмулятор 🖥️

1. Установите [Android Studio](https://developer.android.com/studio)
2. Создайте виртуальное устройство (AVD)
3. Запустите эмулятор
4. Выполните:
   ```bash
   cd frontend
   npm start
   ```
5. Нажмите `a` в меню Expo

---

## ❌ Почему возникает ошибка "No Android connected device"?

Эта ошибка появляется, когда:
- Expo пытается автоматически открыть приложение на Android
- Но не находит подключенное устройство или эмулятор

**Решение:** Используйте **Вариант 1** (Expo Go) - это самый простой способ!
